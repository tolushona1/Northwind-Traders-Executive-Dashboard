# Northwind Traders | Executive Dashboard

An executive level sales dashboard built in Tableau, analysing revenue, customer and order performance for the Northwind Traders dataset - a classic dataset used to practise business analytics.

## About this project

This dashboard was built by following a Tableau tutorial by **Kapil Dhiman** - [Part 1] (https://www.youtube.com/watch?v=oiWFlSucvrA) and [Part 2] (https://www.youtube.com/watch?v=A0f3CYH1d8U) - using the Northwind Traders dataset. I followed the tutorial to learn dashboard design principles and Tableau functionality, then explored the data further on my own to pull out a few observations below.

## What this dashboard covers

-**Key metrics:** Revenue, number of customers, number of orders, average shipping costs per order and average discount
-**Trends:** Monthly revenue and quantity sold performance over time
-**Breakdowns:** Revenue by category orders delivered by shipping company, top customers and top products
-**Interactive filters:** Country, Year, Month and "Top N" parameter to flex between top customers/products

## Tools used

- Tableau (Public)
- Northwind Traders Dataset

## What I noticed

The dashboard's Top Customers view reveals a clear top tier: my three highest customers (Horst Kloss, Jose Pavarotti and Roland Mendel) are all clustered closely together around 113k-118k in revenue but there's a sharp drop-off after that where the 4th ranked customer generates roughly half as much. This kind of concentration could be useful for a business thinking about account management priorities or churn risk if one of those top customers were lost.

## Skills practised

- Dashboard layout and KPI card design
- Parameter-driven "Top N" filtering
- Combining multiple chart types (line, bar) in one view
- Working with filters across Country, Year and Month dimensions
